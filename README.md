# 从零搭建 Agent · 架构学习日志

一个按真实学习与搭建顺序持续更新的可视化项目。通过架构画布、模块说明和阶段记录，展示从最小 Agent 开始逐步构建系统的过程，以及作者与 ChatGPT 讨论、选择和验证方案的协作方式。界面提供十种可切换的视觉风格，共享同一份架构与阶段数据。

**站点：** https://agent-architecture-journey.dingikang.chatgpt.site

> 站点当前为私有发布，仅站点所有者可以访问。GitHub 仓库公开展示源码；如需对外展示网页，之后需要调整站点访问范围。

## 当前进度

`00 / Agent 的定义与最小循环`：已记录四种官方定义的概括、作者的理解、工具反馈循环和 Python 伪代码。画布展示 User → LLM → 按需 Tool → Tool Result → LLM；没有工具调用时返回最终结果。代码为尚未运行的伪代码。完整内容见 [`content/00-agent-definition.md`](content/00-agent-definition.md)。

## 页面内容

- **架构画布：** 点击模块，查看职责。随阶段演进更新节点、关系和状态。
- **逐步演进：** 说明每次增加模块所解决的问题，以及新引入的复杂度。
- **过程记录：** 记录目标与约束、候选方案、作者判断、ChatGPT 建议、实现与验证。
- **目标文档：** [`GOAL.md`](GOAL.md) 是后续编辑的内容约定；网页版本位于站点的 `/goal.html`。
- **十种主题：** 从工作台、极简手册、科幻蓝图到魔幻秘典等，入口在 `/design/`。主题切换保留当前阶段与模块焦点。
- **明暗与中英文：** 顶栏独立切换浅色/深色与中文/English，偏好保存在当前设备；目标文档也提供英文版。
- **页面结构：** `/journey/`、`/stage/00/`、`/architecture/`、`/modules/<slug>/`、`/compare/`、`/about/`、`/design/`。第 0 阶段记录最小循环，第 1 阶段记录工具概念与探索路线。

## 后续阶段如何更新

每完成一个阶段，提供阶段名称、目标与约束、关键问题和讨论方案、自己的判断、架构变化、实现摘要、验证证据、局限及下一步。本站会提炼问题、作者判断、架构变化、验证和下一步，按实际内容更新画布和记录，并把源码同步到此仓库。没有证据的部分保持“设计中”或“未验证”，不会写成已完成。

## 本地查看

不需要安装依赖。进入仓库目录后运行：

```bash
python3 -m http.server 8000 --directory dist
```

打开 `http://localhost:8000`。页面是静态 HTML、CSS 和 JavaScript；点击架构节点查看说明；画布自动适应空间，可用按钮或 Ctrl/Cmd + 滚轮缩放，拖动空白处平移。按 `Ctrl/Cmd + K` 打开命令面板，在右上角切换主题。移动端显示架构文字概览。后续更新时，`GOAL.md` 与网页目标文档应保持一致。

## 更新原则

1. 按作者实际搭建顺序增加阶段，不预设固定技术路线。
2. 清楚区分概念、设计、已实现与已验证。
3. 保留关键取舍和失败尝试，说明作者与 ChatGPT 各自的贡献。
4. 每次站点内容更新后，将对应源码继续推送到本仓库。

## 本轮展示优化

- 阶段选择与当前内容联动；第一阶段在原有循环中聚焦 Tool。
- 画布随可用空间缩放；节点与连线使用同一坐标系。
- 流程示意展示一次工具调用、结果返回与再次判断，支持中途停止。
- 精简重复编号与状态；更大的正文、清晰的模块职责、响应式布局。
- 十种主题、独立明暗和中英文切换继续保留。

静态站点没有接入模型或执行工具的后端；演示只说明调用流程。
